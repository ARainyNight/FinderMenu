# 右键小匣

**给 Mac 的访达右键菜单加几个常用功能：新建文本文件、复制完整路径、按路径跳转、剪切移动文件、显示或隐藏隐藏文件，以及在当前文件夹打开 iTerm。**

访达（Finder）就是 Mac 上用来浏览文件和文件夹的应用，程序坞里的图标是一张蓝白笑脸。安装并启用「右键小匣」后，在访达里右键就能完成下面这些操作。

| 右键菜单 | 能做什么 |
| --- | --- |
| 新建文件 → 新建 TXT 文件 | 在目标文件夹里创建一个空白文本文件 |
| 新建文件 → 新建 Markdown 文件 | 创建一个空白 `.md` 文件，适合写笔记或文档 |
| 复制绝对路径 | 复制文件或文件夹在电脑上的完整位置，方便粘贴分享或在其他工具中使用 |
| 回到上级目录 | 打开上一层文件夹，并选中原来的项目 |
| 路径搜索… | 打开访达「前往文件夹」窗口，输入路径跳转，对应 `Command+Shift+G` |
| 显示／隐藏隐藏文件 | 切换访达隐藏文件的显示状态，效果对应 `Command+Shift+.` |
| 剪切 | 记录准备移动的文件或文件夹，支持多选 |
| 粘贴（移动） | 把刚才剪切的项目移动到目标文件夹 |
| 进入终端 | 用 iTerm 在目标文件夹打开终端窗口 |

不熟悉终端也可以使用新建文件、复制路径和移动功能。「进入终端」需要另外安装 iTerm，其他功能不依赖它。

## 安装前需要知道

- 应用的目标系统为 **macOS 13 或更高版本**，可在苹果菜单的「关于本机」中查看系统版本。
- 本文介绍**从源码构建并安装**的流程。GitHub 的源码 ZIP 是项目文件，不能直接当作应用打开。
- 构建需要支持 **Swift 6 或更高版本**的 Apple Command Line Tools 和 macOS SDK，无需安装完整 Xcode。目标系统版本与构建工具要求不同；较旧系统可安装的工具版本可能不满足 Swift 6，需要先更新系统或开发工具。
- 构建脚本按当前 Mac 的芯片架构生成应用；目前已在 Apple 芯片 Mac 上验证，Intel Mac 和其他系统版本尚未实测。
- 当前使用本地签名，尚未经过 Apple 公证。首次打开可能遇到系统安全提示。
- 「显示／隐藏隐藏文件」和「路径搜索…」需要手动授予控制权限，设置页面在新版系统中叫「设备控制和数据访问」，旧版叫「辅助功能」；具体步骤见下文。

## 一步步安装

### １．准备 Apple 命令行工具

按 `Command + 空格` 打开聚焦搜索，输入「终端」并打开。这里使用的是 macOS 自带的终端，不需要先安装 iTerm。

如果尚未安装 Apple 命令行工具，在终端粘贴下面的命令，按回车，再按照弹窗提示完成安装：

```bash
xcode-select --install
```

如果提示工具已安装，继续检查 Swift 版本：

```bash
xcrun swift --version
```

输出中的 `Apple Swift version` 应为 `6.x` 或更高版本。如果低于 6，先通过「系统设置 → 通用 → 软件更新」检查开发工具更新；安装方式及版本要求见 [Apple 命令行工具说明](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools/) 。

### ２．下载源码

1. 打开 [FinderMenu 项目首页](https://github.com/ARainyNight/FinderMenu) 。
2. 点击绿色的 **Code** 按钮，选择 **Download ZIP**。
3. 下载完成后双击 ZIP 解压，打开解压后的文件夹。
4. 确认里面能看到 `README.md`、`Scripts`、`Sources` 等文件和文件夹。这一层就是后文所说的「项目文件夹」。

源码可以放在你自己选择的位置，不需要创建与作者相同的目录，也不需要登录 GitHub。

### ３．进入项目文件夹，生成应用

1. 回到终端窗口，输入 `cd`，紧接着输入一个空格，先不要按回车。
2. 将刚才的项目文件夹从访达拖进终端。终端会自动填入你电脑上的实际位置。
3. 按回车。后面的命令都在这个终端窗口里依次执行。

先构建应用，等待命令执行完毕：

```bash
bash Scripts/build.sh
```

看到 `Built and verified:` 表示构建成功，再运行检查：

```bash
bash Scripts/verify.sh
```

检查成功后会显示 `Bundle declarations and signatures verified.`。如果出现错误，先根据报错解决问题，不要继续安装不完整的产物。

这两条命令只在项目文件夹内生成应用和验证文件，不会自动安装应用或启用访达扩展。检查成功也不代表右键菜单已经启用，下面还需要手动安装和设置。

### ４．放入「应用程序」并打开

在同一个终端窗口执行：

```bash
open build
```

访达会打开项目内的 `build` 文件夹，其中的 `FinderMenu.app` 就是生成的应用。访达可能将它显示为中文名称「右键小匣」。

1. 将这个应用拖到访达侧边栏的「应用程序」中。
2. 打开「应用程序」，双击「右键小匣」。后续也从这里打开应用。
3. 如果系统因开发者身份或未公证而阻止打开，确认来源可信后，按 [Apple 的打开说明](https://support.apple.com/zh-cn/102445) ，在「系统设置 → 隐私与安全性」中找到本应用对应的「仍要打开」，再按提示确认。

### ５．启用访达扩展

1. 在「右键小匣」主窗口中点击 **「管理扩展…」**。
2. 在系统打开的扩展管理界面中找到访达相关扩展，开启 **「右键小匣」**。
3. 回到应用主窗口，确认状态显示 **「Finder 扩展已启用」**。
4. 在访达中打开一个普通文件夹，右键空白处，检查是否出现「新建文件」「复制绝对路径」等菜单。

不同 macOS 版本的设置位置和名称可能不同，优先使用应用里的「管理扩展…」按钮。较新版本也可以从「系统设置 → 通用 → 登录项与扩展」查找，参考 [Apple 扩展设置说明](https://support.apple.com/zh-cn/guide/mac-help/mtusr003/mac) ，并选择与你的系统对应的版本。

## 第一次使用

### 新建一个文本文件

1. 在访达中打开你想存放文件的文件夹。
2. 在文件列表的空白处右键。使用触控板时，可以双指点按；也可以按住 `Control` 再点按。
3. 选择「新建文件 → 新建 TXT 文件」。
4. 新文件默认名为「新建文件.txt」，创建后会被选中；按回车即可重命名。

新建 Markdown 的操作相同，只需改选「新建 Markdown 文件」。两种文件初始内容都为空；同名文件已存在时，会自动使用「新建文件 2.txt」等名称，不覆盖原有内容。

### 复制文件的完整路径

右键一个文件或文件夹，选择「复制绝对路径」，再到需要的位置粘贴。右键空白处会复制当前文件夹的位置；多选同一文件夹里的项目时，每行复制一个路径。

### 显示或隐藏隐藏文件

在访达的文件、文件夹或空白处右键，选择「显示／隐藏隐藏文件」。每次点击切换一次，效果对应访达自带的 `Command+Shift+.`；它切换访达的显示状态，不修改文件的隐藏属性，也不限定于右键的目标文件夹。

首次使用需要手动授予权限：打开「系统设置 → 隐私与安全性 → 设备控制和数据访问」（旧版系统为「辅助功能」），点击添加按钮，从「应用程序」中选择「右键小匣」并开启。缺少权限时，应用会提示操作步骤。授权后如果仍提示权限不足，请退出并重新打开「右键小匣」，再回到访达点击菜单；系统的事件发送权限检查可能不会在原进程中立即更新。

重新构建并替换应用会改变本地签名，系统可能需要重新确认权限。此时应核对权限列表中的应用是否来自「应用程序」中的安装版，再按上述步骤授权并重启应用。

点击菜单后请保持访达在前台；如果已经切到其他应用，这次操作会停止并提示重试。也可以直接在访达按 `Command+Shift+.`，手动使用系统快捷键无需给本应用授权。

### 按路径前往文件夹

在访达的文件、文件夹或空白处右键，选择「路径搜索…」，即可打开当前访达窗口的「前往文件夹」，效果对应 `Command+Shift+G`。输入目标文件夹的路径并确认后，由访达完成跳转；它使用当前窗口，不会先打开右键选中的文件夹。

此功能与「显示／隐藏隐藏文件」共用上述控制权限。点击后请保持访达在前台，切换到其他应用时会停止并提示重试。也可以在访达直接按 `Command+Shift+G`，手动使用系统快捷键无需给本应用授权。

### 把文件移动到另一个文件夹

1. 选中要移动的文件或文件夹，右键选择 **「剪切」**；可以多选同一文件夹里的项目。
2. 在访达中打开目标文件夹。
3. 右键空白处，选择 **「粘贴（移动）」**。也可以直接右键目标文件夹，选择这项操作。
4. 成功后，源位置不再保留这些项目，目标位置会选中移动结果。

「剪切」只记录准备移动的项目，点击时不会改变原文件。必须使用本工具的「粘贴（移动）」菜单执行移动，普通的系统粘贴不会代替它。

如果目标里已有同名项目、源项目已不存在，或试图将文件夹移入自身及其子文件夹，会在移动前停止整批操作并提示，不覆盖已有内容。移动途中发生错误时，可能已有部分项目完成；应用会提示完成数量，并保留未完成项目供重试。

剪切后复制其他内容，包括点击「复制绝对路径」，会取消这次待移动记录；再次剪切会替换原记录。

### 在当前文件夹打开 iTerm

如果需要这个功能，先从 [iTerm 官网](https://iterm2.com/downloads.html) 下载适合你系统的版本，放入「应用程序」并打开一次。

然后在访达中右键目标文件夹或文件夹空白处，选择「进入终端」，即可在该位置打开 iTerm 窗口。这里调用的是 iTerm 的 `New iTerm2 Window Here` 系统服务。

如果提示服务不可用，确认 iTerm 已安装，再到「系统设置 → 键盘 → 键盘快捷键 → 服务」中查找并启用 `New iTerm2 Window Here`；它通常位于「文件和文件夹」分类下。

## 右键的位置会影响操作目标吗？

会。新建文件和进入终端按下面的规则选择目标文件夹：

| 右键的位置 | 操作目标 |
| --- | --- |
| 文件夹里的空白处 | 当前打开的文件夹 |
| 单个文件夹 | 这个文件夹内部 |
| 单个文件或应用包 | 它所在的文件夹 |
| 多个同级文件或文件夹 | 它们共同所在的文件夹 |

「复制绝对路径」复制选中项目自身的位置。「回到上级目录」打开选中项目的上一层，并选中原项目；右键空白处时返回当前文件夹的上一层。磁盘根目录下不显示「回到上级目录」。

## 常见问题

**右键没有出现菜单？**

先确认已把应用放入「应用程序」并打开，再通过「管理扩展…」启用访达扩展。重新打开一个普通本地文件夹测试，避免同时打开项目构建目录里的应用副本。iCloud 和受保护目录的兼容性尚未实测。

**为什么没有「剪切」或「粘贴（移动）」？**

「剪切」需要右键选中的文件或文件夹，空白处不显示。先剪切项目后才会出现「粘贴（移动）」；剪贴板被其他复制操作替换后，它会消失。

**已经开启权限，为什么「显示／隐藏隐藏文件」仍提示未授权？**

先退出并重新打开「右键小匣」，再回访达重试。如果刚刚重新构建并替换了应用，还需要核对安装版的权限，因为本地签名已经变化。权限页名称和操作步骤见上文「显示或隐藏隐藏文件」。

**不想一直开着主窗口？**

可以关闭主窗口，之后从菜单栏的「右键小匣」入口重新打开。主窗口也能选择一个操作文件夹，直接使用「进入 iTerm」「新建 TXT」「新建 Markdown」快捷入口。

**支持所有磁盘和文件夹吗？**

目前主要验证了普通本地目录。跨卷移动、iCloud 和受保护目录仍待实测；没有写入权限时会提示错误。

## 项目说明

「右键小匣」的工程名为 FinderMenu，使用 Swift、AppKit 和 Finder Sync 实现，无第三方代码依赖。构建脚本、源码和测试分别位于项目内的 `Scripts`、`Sources`、`Tests` 文件夹。

开发进度、验证记录和待确认事项见 [ROADMAP.md](ROADMAP.md) 。
